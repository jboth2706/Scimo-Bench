# M8 — Snakemake workflow on cluster sites

Size M · depends on: M7 (all steps exist) · next: post-MVP

## Goal
Run the steps of a cluster call as a Snakemake workflow instead of hand-written sbatch
chains: one GPU job per model for `predict` (parallel), one `perf` job for all models (same
GPU, comparable timings), then `score` and `plot`; a Snakemake profile per site; reruns of
what is missing or changed only.

## Deliver
- `pixi.toml`: feature `workflow` (Snakemake 9, `snakemake-executor-plugin-slurm`, PyPI) in
  the default env.
- `workflow/Snakefile`: rules `predict` (wildcard `model`), `perf`, `score`, `plot`,
  `command`; reads only `workflow.json`; markers `status/<step>.done`, logs
  `logs/<step>[-<model>].log`; a config hash per step as `params` (rerun trigger);
  `<step>_cpu` model rules for `runtime=cpu`.
- `workflow/profiles/{raven,viper,local}/config.yaml`: executor and job resources (the GPU
  rules `predict`, `perf`, `command_gpu`); `local` runs the jobs on this machine.
- `scimo_bench/workflow.py`: snapshot, job scripts (`jobs.job_script`), `workflow.json`,
  Snakemake in the run folder (blocks); `--force` → `--forcerun` of the requested steps;
  CLI `python -m scimo_bench.workflow <site> -- <command>` (`pixi run test-job raven`).
- `scimo_bench/jobs.py`: sbatch script, submission, `jobs.csv` and the jobs CLI removed;
  `configs/sites.py`: `resources`, `wait` removed, `profile` added.
- Top-level config `only=<model>` (the model a predict job runs); per call
  `site.set_resources` (merged into the profile) and `site.snakemake_args`.

## Done when
- `tests/test_workflow.py` green: local-profile workflow with two toy models; an unchanged
  call does nothing; a changed model reruns only its predict job (+ perf, score, plot);
  `--force` reruns all; a failing model is `missing`; dry runs of the raven and viper profiles
  show the GPU resources.
- On Raven: a run of `tok_n5_20M` and `cont_split_n5_20M` (`perf=single`,
  `cutflow=preselection`) shows two parallel predict jobs, one perf job, then score and plot;
  its `report.csv` matches the earlier run. A third model added to the run predicts alone.
- On Viper: a smoke run from viper11–13.
