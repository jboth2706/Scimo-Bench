# M0 — Scaffold

Size S · depends on: nothing · next: M1

## Goal
An empty but runnable SciMo-Bench: the environment, the entry point, hydra-zen config groups
and the output folder. No physics yet.

## Deliver
- `pixi.toml` (exists as a draft; finish it): env `default` (python 3.12, numpy, pandas,
  pyarrow, awkward, uproot, matplotlib, scipy, hydra-core, hydra-zen, pytest, ruff); feature
  `perf` with pytorch and hep4m_scimo (editable `../scimo`) — leave `perf` unused until M6.
  Tasks: `test`, `lint`, `fmt`.
- `run.sh` (exists): `pixi run python -m scimo_bench "$@"`.
- `scimo_bench/__init__.py`, `__main__.py`, `main.py`: one hydra-zen entry point
  (`hydra_zen.zen(...).hydra_main(...)` or `@hydra.main` over the store). Registers the
  resolvers `linspace(a,b,n)` and `logspace(a,b,n)` (lists, `.tolist()`) before composition.
- `scimo_bench/configs/`: modules `models.py`, `tasks.py`, `cutflows.py`, `plots.py`,
  `output.py`, `perf.py`, each with its store group; a top-level config with defaults
  `task=???`, `models=[]`, `cutflow=null`, `plots=default`, `output=default`, `perf=null`,
  `stage=all`. A `dummy` model and a `pflow` task stub (no metrics yet).
- Output config: `dir = outputs/${task.name}/${now:%Y-%m-%d_%H-%M-%S}`, `formats=[png,pdf]`,
  `bootstrap={n: 1000, level: 0.95}`, `on_missing=warn`, `seed=0`.
- Per run: `resolved_config.yaml` and `run.log` (git commit of this repo, call arguments).
- `ruff` config in `pixi.toml` or `pyproject.toml` (line length 100), `.gitignore` for `outputs/`.

## Done when
- `./run.sh task=pflow 'models=[dummy]'` composes, creates the output folder with
  `resolved_config.yaml` and `run.log`, exits 0.
- A test composes the config with a misspelled `builds` argument and expects a failure at
  compose time.
- `${linspace:0,2,51}` resolves to 51 floats in a test.
- `pixi run test` and `pixi run lint` pass.
