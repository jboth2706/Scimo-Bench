# M5 — Plotter

Size S · depends on: M4 · next: M7

## Goal
All plots of a task for all models in shared axes; redraw from CSVs.

## Deliver
- `scimo_bench/plotter.py`: `@register_plot(name)` registry; for a name in the task's plot
  list: a registered plot, else a variable → its distribution.
  - distribution: truth as grey filled histogram, models as step histograms, optional ratio
    panel (model / truth), normalization `density` by default, reference lines from the
    variable metadata.
  - `metric_vs_x` (e.g. `response_vs_pt`, `efficiency_vs_pt`): one line per model with its
    interval band, from `report.csv`.
  - `ranking`: bars or table from `rankings.csv`.
- Plot specs (labels, binning, ratio panel, normalization) in `configs/plots.py` via
  hydra-zen; binning via the resolvers.
- Fixed style per model (colour, line style) assigned from the model's position in a stable
  palette by model name, identical across plots and runs.
- `stage=plot`: redraw from an existing output folder (`output.dir=<folder>`) without
  loading predictions (distributions from `per_event.parquet`).

## Done when
- Plots for the two n6 models (or two synthetic models before M2) in `plots/` as png + pdf.
- Redraw with `stage=plot` gives identical files.
- The plotter module imports nothing from `variables.py` except metadata (labels, units).
