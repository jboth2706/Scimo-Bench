# M3 — Variables and cutflow

Size M · depends on: M1 · next: M4

## Goal
All physics quantities of `pflow` as registered variables, and cuts built on them.

## Deliver
- `scimo_bench/variables.py`: `@variable(name, level="event"|"object", label=, unit=,
  reference=)` registry; `get(name)`; a variable receives `(truth, pred, ctx)` after cuts and
  returns an array (per event or jagged per object) or raises `MissingInput(field)`.
  For `pflow`:
  - jet from the vector sum of particles (massless, as `pflow_report._compute_jets`):
    `jet_truth_pt/eta/phi/e`, `jet_pred_*`, `jet_energy_response = E_pred / E_truth`,
    `jet_pt_response`, `jet_dr`.
  - particle matching truth ↔ prediction, greedy by truth pT within ΔR < threshold
    (threshold from the task, default 0.05): `particle_matched` (per truth particle),
    `particle_fake` (per predicted particle), `particle_dr`, `particle_pt_response`.
  - `event_emd`: unbalanced EMD with ΔR cost capped at R = 1 (port
    `pflow_report._compute_emd_event`; POT is a new dependency).
  - `n_truth`, `n_pred`, `multiplicity_diff`.
- `scimo_bench/cutflow.py`: `@cut(name, level=, variable=)` registry; for `pflow`:
  `min_pt`, `max_abs_eta` (object level, on truth and prediction alike), `min_particles`
  (event level). Cut configs in `configs/cutflows.py` (`central`: |η| < 2.5, pT > 1 GeV,
  ≥ 1 particle).
- `cutflow.csv`: events/objects remaining after each step, per model (the event set is
  shared, object counts per collection).

## Done when
- Known-answer tests with `tests/synthetic.py`: identical → response 1, EMD 0, all matched,
  no fakes; pT × 1.1 → response 1.1; dropped particles with p → matched fraction 1 − p.
- A model without `particles.e` → energy variables raise `MissingInput`, pT variables work.
- Cutflow counts identical for all models on the same events.

## Notes
- Invariant 4: no physics outside `variables.py`. The scorer and plotter only call `get()`.
