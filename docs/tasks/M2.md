# M2 — Producer: nanoHEP predictions (in hep4m_scimo)

Size L · depends on: M1 (contract) · next: M6 · **work happens in `/raven/u/jboth/scimo`**

## Goal
A class `hep4m_scimo.bench:NanoHEP` implementing the model protocol (`docs/PROTOCOL.md`), so
that scimo-bench generates the `pflow` predictions itself (`steps=[predict]`, GPU job):
truthpart generated from topo + track on the task's events, multiplicity from the model.
The model type `nanohep` in `scimo_bench/configs/models.py` already points at this class.

## Deliver (in hep4m_scimo, on a new branch from the current dev branch; ask which)
- `src/hep4m_scimo/bench.py` (or a `bench/` package), class `NanoHEP`:
  - `load(cfg)`: model from `ckpt["hep4m_config"]` via `assemble_model` (checkpoint in
    `cfg["checkpoint"]`), honouring `cfg["runtime"]` (device, precision, compile); the
    tokenized val data and the truthpart decoder from `cfg["options"]`.
  - `inputs(event_ids, size)`: the decoding prefixes of these events
    (`load_event_chunks` / `TokenStreamEncoder.build_prefix`), on the device.
  - `generate(batch)`: `decode_chunk` (structural decode on, stop at EOS), argmax or
    temperature per `cfg["generation"]`.
  - `to_floats(out)`: tokens → per-particle codes (`vocab.decode_element_with_pos`) →
    `pt, eta, phi, e`. Positions from bins (bin centres, φ = atan2(sin φ, cos φ)); pT/E from
    content codes via the exported truthpart VQ-VAE decoder (`scripts/export_decoders.py`,
    `scripts/pflow_report.py: load_decoder, decode_pt_batch`). E = pT·cosh η if the decoder
    gives only pT (say so in `info()`).
  - `info()`: family `token_ar`, n_params, generation, checkpoint, tokens per event.
- Export of the truthpart decoder (as a job, not on the login node) if it does not exist.

## Done when
- `./run.sh site=raven models_file=examples/hep4m_models.py task=pflow
  'models=[nanohep_n6_adamw,nanohep_n6_muon]' steps=[predict,score]` writes two valid
  prediction files on the 20,000-event val subset and scores them.
- Check: decoding the *truth* tokens of the same events through `to_floats` reproduces the
  ROOT truth up to the position binning (|Δη| ≤ bin width) and the decoder's pT resolution;
  the ~4 % events with one missing soft particle are reported, not hidden.
- Unit tests in hep4m_scimo for the tokens → floats conversion (bin centres, φ wrap).
