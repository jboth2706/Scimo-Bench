# M1 — Contract and IO

Size M · depends on: M0 · next: M2, M3

## Goal
Read predictions written against `docs/CONTRACT.md`, read the COCOA truth into the same
shape, and join them per event. Synthetic data with known answers for all later tests.

## Deliver
- `scimo_bench/schema.py`: field names and types of contract v1, a `Meta` dataclass,
  `validate(array, meta, task) -> list[str]` (problems, not exceptions), `schema_version`.
- `scimo_bench/io.py`:
  - `read_predictions(path) -> (awkward.Array, Meta)` (single file or `part-*.parquet`).
  - `read_truth_cocoa(path, event_ids=None) -> awkward.Array` from the ROOT branches
    `particle_pt/eta/phi/e/pdgid` + `eventNumber`, as `particles.*` + `event_id`.
  - `join(truth, preds_by_model) -> Joined`: inner join on `event_id` (and `sample_id`);
    the common event set is the intersection over all models (invariant 5); counts of
    dropped events per model go to the log and to `cutflow.csv` (step `join`).
  - duplicate truth particles (identical pT, η, φ within an event) dropped and counted.
- `tests/synthetic.py`: generators for truth + predictions: identical, shifted pT by a known
  factor, Gaussian-smeared, particles dropped with known probability, events missing, a field
  missing. Write them as contract files in a tmp dir.

## Done when
- On the real val file: all 99,955 events are read; the join of truth with a synthetic
  "identical" prediction loses no events; the duplicate count equals 413 pairs.
- Tests: round-trip write/read of a contract file; `validate` reports a missing required
  field; join with missing events drops exactly those and reports the count.

## Notes
- Truth path and branch names: `docs/HEP4M_CONTEXT.md`.
- Use awkward + pyarrow for Parquet; keep ROOT reading in `io.py` only (uproot).
- Reading the full ROOT file on the login node is fine (it is analysis, not training); keep
  tests on small synthetic files.
