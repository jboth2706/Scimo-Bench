# M4 — Scorer

Size M · depends on: M3 · next: M5, M7

## Goal
Metrics with intervals, status and rankings for all models at once; the report files.

## Deliver
- `scimo_bench/scorer.py`:
  - metric building blocks as classes used via `builds(...)` in task configs: `Median`,
    `Quantile(q)`, `IQR`, `Mean`, `Std`, `Efficiency` (fraction of truth objects matched),
    `FakeRate`; each optionally binned in `x` with explicit edges.
  - paired bootstrap over events (same resampled event indices for all models), `n` and
    level from the output config, fixed seed; value + lower + upper.
  - status: `ok`; `missing` (variable raised `MissingInput`, warning, run continues);
    `invalid` (empty denominator, empty bin).
  - ranking: per metric by `better` (`lower`, `higher`, `{closest_to: v}`), `primary`
    metric and `mean_rank`; models with `missing` ranked last and marked.
  - optional normalized score s = (m − m_base) / (m_ref − m_base) when the task names a
    baseline and reference that are among the models.
- Files: `report.csv` (columns in `docs/DESIGN.md`, with `kind=quality`, `task_version`,
  `condition` = hash of `meta.generation`), `rankings.csv`, `per_event.parquet`.
- Task `pflow` metrics (in `configs/tasks.py`): `emd_median`, `response_median` and
  `response_iqr` in truth-pT bins, `efficiency` and `fake_rate` in pT bins,
  `multiplicity_diff_mean`.
- No synthetic baseline producer: the benchmark only compares model predictions with
  the truth (decided 2026-10-21). `normalization.baseline` names one of the real models.

## Done when
- Values equal numpy references on synthetic data; bootstrap coverage of the true median
  ≈ 95 % over 200 toy repetitions (tolerance ± 3 %).
- A model with a missing field produces `missing` rows and the other metrics, no abort.
- `report.csv`, `rankings.csv`, `per_event.parquet` written for two synthetic models and,
  once M2 is done, for the two n6 models.
